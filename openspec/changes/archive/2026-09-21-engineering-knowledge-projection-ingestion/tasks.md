## 2. Atomic persistence and lifecycle behavior

- [x] 2.1 Stage extraction/normalization outside SQLite transactions, then persist each complete source unit through the concrete Store's atomic save operation.
  - Evidence (2026-09-20): `SqliteKnowledgeProjectionIngestion` validates and fully normalizes each accepted source unit before calling `SqliteKnowledgeStore.save` exactly once with its complete `ProjectionWrite`. It neither opens nor widens a transaction itself; parsing and provenance construction therefore remain outside the Store's existing short validate/upsert/commit-or-rollback transaction.
- [x] 2.2 Implement source-unit failure isolation and report saved, unchanged, stale, failed, and unsupported outcomes without partial persisted rows or falsely global success.
  - Evidence (2026-09-20): the coordinator preserves request order and handles validation rejections, normalization failures, and atomic Store failures as per-unit structured reports, then continues with independent units. Request-level validation rejects all listed units before persistence; unsupported ripgrep remains explicit; a failed Store call reports zero committed objects/evidence and relies on the Store rollback contract, while `IngestionReport.fullySuccessful()` rejects mixed/failed outcomes.
- [x] 2.3 Implement stable identity plus input-hash/profile comparison for idempotent unchanged reports and Store-driven stale/retryable transitions; do not run Lucene or external tools inside writes.
  - Evidence (2026-09-20): the coordinator compares every stable projected object, input binding, lifecycle, input hash, and generator/profile outside the write transaction. Exact current replays report `UNCHANGED` without writing; new units report `SAVED`; changed input/profile projections save atomically and report `STALE`. The Store's additive `save(ProjectionWrite, List<ProjectionReplacement>)` overload marks older versions for the same canonical source/generator stale in the same existing transaction without a schema change, Lucene call, or external tool execution.
