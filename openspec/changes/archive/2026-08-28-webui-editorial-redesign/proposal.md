## Why

当前 WebUI 已覆盖检索、问答、会话和管理工作区等核心流程，但页面的视觉层级、排版节奏和响应式体验较为基础，难以让用户快速聚焦当前任务。现在重设计能在不扩大后端范围的前提下，建立更清晰、可信且适合长期使用的个人知识库界面。

## What Changes

- 以简洁、克制的欧美编辑式视觉语言重构使用页和管理页：统一色彩、排版、间距、卡片、表单和反馈状态。
- 强化使用页中“当前工作区、检索/问答、会话”的信息层级，并保持已有工作流与服务端 API 不变。
- 让管理页的工作区和内容维护操作具有更明确的分区、状态提示和移动端布局。
- 将已有 HTTP API 支持的管理能力页面化：服务/工作区状态、工作区修复与移除、索引重建、根目录查看与移除，以及服务器本地路径导入。
- 为键盘操作、焦点状态、语义标签及窄屏布局补齐可访问性与响应式细节。
- 仅使用本地 HTML、CSS、JavaScript 与系统字体；不新增前端框架、远程资源或运行时依赖。

## Capabilities

### New Capabilities

- `webui-editorial-redesign`: 为知识库 WebUI 提供统一、可访问、响应式的编辑式界面体验，同时保持既有功能和接口兼容。

### Modified Capabilities

- 无。

## Impact

- 受影响前端资源：`webui/index.html`、`webui/manage.html`、`webui/styles.css` 及相关 JavaScript。
- 同步更新打包资源：`src/main/resources/webui/`。
- 可能更新 WebUI 静态资源契约测试；复用既有 HTTP API，不新增后端端点。工作区存储、会话及导入/同步行为不变。
