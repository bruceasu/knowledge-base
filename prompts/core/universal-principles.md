# Universal Principles

## Task Size
- Local tasks can often be solved with a small focused edit.
- Repository-level tasks need planning because code and contracts are spread across many files.

## Change Discipline
- Understand the task before editing.
- Change only what the task needs.
- Keep diffs small and easy to review.
- Follow local patterns before inventing new ones.

## Evidence Discipline
- Separate facts, assumptions, and inferences.
- Static evidence is acceptable when runtime validation is not authorized.
- Do not present static evidence as a runtime result.
- Call out what remains unverified.

## Stop Instead Of Guessing
- stop when local instructions conflict
- stop when external behavior is unclear
- stop when rollout or migration expectations are missing
